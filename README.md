# Temperature-Dependent Consumer-Resource Model

This repository contains MATLAB codes I developed to study the eco-evolutionary dynamics of a consumer-resource model where parameters depend on temperature. The model includes phenotypic change, spatial dispersal, and several types of analyses depending on the research question.

## Contents

- **Parameter sweeps**: Scripts to explore how the system’s behavior changes when varying growth rates, dispersal, costs of phenotypic change, and other key parameters.
- **Time series**: Simulations showing the temporal dynamics of prey and consumers (native and exotic), as well as their trait evolution.
- **Metapopulation model with dispersal**: A spatial version of the model that incorporates patch-to-patch movement.
- **Average density and extinction probability**: Scripts that calculate population-level metrics under different environmental and evolutionary scenarios.
- **Chaos analysis (Poincaré section)**: Code to detect complex dynamics, such as periodic or chaotic behavior, through numerical tools.

## How to use

1. Open any of the scripts in MATLAB.
2. Modify parameters or initial conditions if needed.
3. Run the simulation to generate results or figures.
